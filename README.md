# MovieBoat

python 版本 `3.12+`

```shell
pip3 install -r requirements.txt
python3 main.py
```

打开`http://localhost:8080` 即可查看网站

前端页面基于 `Bootstrap 5` 进行了现代化重构，并新增了图片死链自动兜底占位图。

单元测试运行方式：

```shell
pytest -q
```
